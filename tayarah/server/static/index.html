🌐 Native Ollama & vLLM API Access

Tayarah runs transparently as a drop-in replacement for both Ollama and vLLM / OpenAI endpoints. 

# Stream via Ollama API
curl -N http://127.0.0.1:11435/api/generate \
  -d '{
    "model": "tayarah",
    "prompt": "Hello Tayarah!",
    "stream": true
  }'
# Stream via vLLM / OpenAI SSE API
curl -N http://127.0.0.1:11435/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tayarah",
    "messages": [{"role": "user", "content": "Hi"}],
    "stream": true
  }'
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:11435/v1",
    api_key="tayarah"
)

stream = client.chat.completions.create(
    model="tayarah",
    messages=[{"role": "user", "content": "Fly fast!"}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

Available Endpoints:

  • POST /api/generate — Ollama Streaming NDJSON
  • POST /api/chat — Ollama Chat NDJSON
  • POST /v1/chat/completions — OpenAI Server-Sent Events
  • GET /v1/models — Model Catalog
  • GET /api/tags — Ollama Tags
